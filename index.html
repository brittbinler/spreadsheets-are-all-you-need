How it works

Each notebook is one self-contained .html file. Open it, paste in your own OpenAI API key (stored only in your browser), and run steps that mix spreadsheet cells, JavaScript, and AI prompts. To import your own CSV, open a notebook and use the import option inside it, or drop your data directly into a cell.
